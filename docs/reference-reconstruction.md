# 参考图反推提示词 → 纯文生图重新生成

本功能是从参考图片提取画面描述，再仅用文字生成新图（“洗图”），**不是图生图、原图低强度重绘或像素级还原**。

## 可复用工作流

- 输入 `reference_images` 是有序图片列表，描述可留空。
- 第一步用普通条件节点判断图片列表是否非空。
- 有图：Hermes `aixg` 反推提示词 → 整理文本 → 纯文生图。
- 无图：原有文字润色（如场景配置有此步骤）→ 整理文本 → 同一个纯文生图步骤。
- 反推步骤设置有图执行的 `runCondition`；文字润色可设置无图执行。最终 ComfyUI 生图步骤不设这两个分支条件，不需要两个生成器或结果选择节点。
- 原图只绑定反推步骤。整理步骤消费反推文本和可选用户要求；ComfyUI 只绑定正向/负向提示词、画幅、像素等参数。
- 不添加 `LoadImage`、`VAEEncode`、图像条件、参考 latent 或输入重绘强度。纯文生图从空 latent 采样。
- 路由、Profile、输入引用和模型参数都由工作流声明，Studio 和执行引擎不按场景名称硬编码。

可导入 `examples/scenes/text-to-image-reference.json`，确认本机 Hermes Profile 和纯文生图模型文件。正式示例使用 `Zane/t2i_UI.json`，不再引用 `reference-reconstruction_UI.json`。基础默认定义的 ComfyUI 文件仍为待配置占位，不替用户选择模型。独立的图生图场景不受影响。

## 提示词要求

反推结果必须是独立、具体的画面描述，不能是“保持原图”“第一张参考图”等依赖图片的编辑指令。按全景、前中后景和左右层级描述主体数量、位置、相互关系、构图、背景、材质、光线和风格。不臆测无法辨认的文字和不可见细节。

多张图片以第一张为主画面，其他图片只补充同一主体的可见信息。描述为空时不要求额外填写文字；有补充要求时只应用明确修改。整理步骤不重写成自由联想或图生图指令。

提示词能保留可描述的主体与场景语义，但纯文生图不会保留原图像素、精确几何、字体或细微位置。测试应分别核对链路正确性和视觉相似程度，不能用图生图替代需求，也不能只凭 `completed` 宣称完全一致。

## 验证

- `npm test`：默认与导入场景均仅一个 T2I 步骤；空描述单图、多图、用户补充要求、无图空列表与省略图片；仅反推携带图片，生成器消费文本；其他通用能力回归。
- `npm run typecheck` / `npm run build`：前后端类型检查与生产构建。
- `node scripts/smoke-reference-reconstruction.mjs <有图运行ID> <无图运行ID> [服务URL]`：验证两个已完成真实运行及实际 ComfyUI history，不再提交模型请求。检查有图反推完成、无图跳过、生成步骤相同、提示词实际绑定、空 latent、无原图加载/编码/图像条件，以及归档结果可访问。
- 真实端到端测试需要查看有内容的原图和新生成图，并记录相似点、差异与限制。
