# H3 数字人长视频 · AIXG 全流程

## 使用入口

生产系统：`http://127.0.0.1:8799/` → 创作场景 → **H3 数字人长视频**。

上传一段完整音频、按顺序添加 1 至 6 张参考图，设置输出宽高比和百万像素，选择 `speaking`（口播）或 `singing`（演唱），填写素材说明，并按需补充创作引导后点击“运行流程”。宽高比默认 `16:9 (Widescreen)`，百万像素默认 `0.7 MP`；可选比例与 H3 工作流的 `ResolutionSelector` 节点一致。

- 音频：WAV / MP3 / OGG，每次一个文件。
- 参考图：按上传顺序对应 `<Picture 1>` 至 `<Picture 6>`。顺序会同时传给 Hermes 和 H3。
- 素材说明：写清每张图的人物、服装、环境等用途。例如：“图1是人物身份，图2是唯一环境，人物坐在图2桌前面向镜头自然口播，固定机位。”
- 创作引导：可选的多行自然语言输入，内部字段为 `creative_guidance`。可以直接粘贴剧本、视频脚本要求、表演情绪、运镜、节奏或视觉风格；留空沿用音频分析和素材说明。
- 图片格式：PNG / JPEG / WEBP / BMP / GIF；H3 单张读取上限为 32 MiB。

## 传入剧本与视频要求

在“创作引导（剧本 / 视频脚本要求）”中输入自然语言，例如：

```text
全片像是在向一位老朋友讲述往事，情绪克制，服装和环境保持一致。
0–10秒：看向镜头，平静开场。
10–20秒：进入回忆，眼神短暂移开，语速和口型跟随原音频。
后半段：情绪逐渐释然，结束时重新与镜头对视。
```

这份引导会传给每一段 AIXG，同时提供当前分段的分析结果和全片分段数量。全片要求跨段保持一致；有时间点或段落标记时，对照当前段原音频的 `start`、`end` 和 `index` 选取适用要求；没有时间点时，结合当前段内容提炼表现，不重复整份剧本。用户明确指定的表演、构图、运镜和风格优先于自动分析的默认导演建议。原始音频仍决定分段和口型时序。

字段配置为 `textarea`、非必填；Hermes 步骤输入引用为 `input.creative_guidance`，提示词模板通过 `{{input.creative_guidance}}` 注入。其他场景也可以用同样的输入与引用方式接入自然语言要求。

## 三个步骤

1. **H3 音频分段分析**：自己的 `ComfyUI-Zane` 节点包内的 `ZaneH3AudioAnalyzeExport`，工作流 `Zane/h3_audio_analyze.json`。目标 11 秒，最长 15 秒，保留原始采样边界及帧数。
2. **AIXG 逐段写 H3 提示词**：Hermes Profile 固定 `aixg`；每段收到结构化分析及真实图片附件，返回 `{task:{index,prompt}}`。失败即停止。
3. **H3 顺序生成并合成长视频**：读取指定 JSON，写回每段提示词和参考图，调用 H3 原生审核、顺序生成、裁切与合成接口，将完整视频归档到运行结果。

## 已适配的规则

- Hermes 只改提示词；段号、音频边界、剪辑帧数和生成帧数由 H3 保留。
- AIXG 可以自由组织当前段的创作提示词，不需要输出 H3 固定标题或模板；系统提交前会自动适配六段结构、有效参考图和单镜头协议。
- 采用 H3 原插件的格式规范化，清理章节中的 Shot 标记并合并为当前分段的单镜头表达。
- `performance` 使用音频参考；`atmosphere/environment` 不引用 `<Audio 1>`。两个声音章节均为 `N/A`，由原生合成恢复原音频。
- 宽高比和百万像素输入绑定到 `ResolutionSelector` 节点 `115`，由该节点计算宽高并传给 H3；默认 `16:9`、`0.7 MP`（工作流原始配置）。最终视频输出绑定到 `VHS_VideoCombine` 的 `Filenames` 输出；H3 适配器将已合成 MP4 作为视频结果返回。保持帧数、原音频、文件名前缀及 fps 连接。只提交最终视频的依赖节点，画布标签及 rgthree 分组开关不进入执行图。
- 本机 `SelfLiftAvatarH3Sampler` 要求标准 Euler。场景将 `265.sampler_name` 绑定为 `euler`；原 JSON 保存的是 `er_sde`。这项覆盖保存在场景配置中。
- 当前 H3 模型的文本维度为 5120；场景将 `128.clip_name` 绑定为已安装且有成功记录的 `qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors`。原 JSON 的 8B 编码器维度为 4096，会触发矩阵维度不匹配。
- 取消及超时会请求 H3 停止；原始 ComfyUI 节点报错会附在失败信息中。
